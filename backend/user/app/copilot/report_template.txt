# '#'으로 시작하는 줄은 보고서에 나오지 않습니다. {이름} 자리에는 DB의 숫자가 들어갑니다.
#
# 쓸 수 있는 자리 표시:
#   {date}                 2026. 11. 24.(화) 기준 날짜
#   {total}                전체 인원           {active}              복무 중 인원
#   {unassigned}           편성 대상 중 미편성  {held}                보류 상태 인원
#   {approved_hold}        승인된 보류 인원     {approved_delay}      승인된 연기 인원
#   {targets}              올해 교육 대상       {done}                교육 이수 인원
#   {done_pct}             이수율(예: 82.4%)    {short}               교육 시간 미달 인원
#   {prosecution}          고발 검토 대상       {pending_postponements} 결재 대기 보류·연기 신청
#   {incomplete_documents} 그중 서류 미비       {pending_transfers}   전입 확인 대기
#   {issues}               이상 데이터 요약 문장
#
# 줄을 지우거나 순서를 바꿔도 됩니다. 위에 없는 {이름}을 쓰면 그 자리는 {이름} 그대로 나옵니다.
[예비군 현황 보고] {date} 기준

1. 인원 현황
  - 전체 {total}명 (복무 중 {active}명)
  - 편성 대상 중 미편성 {unassigned}명
  - 보류 상태 {held}명 (승인된 보류 {approved_hold}명, 승인된 연기 {approved_delay}명)

2. 교육 현황
  - 올해 교육 대상 {targets}명 중 이수 {done}명({done_pct}), 미달 {short}명
  - 고발 검토 대상 {prosecution}명

3. 결재 현황
  - 보류·연기 신청 결재 대기 {pending_postponements}건 (서류 미비 {incomplete_documents}건)
  - 전입 확인 대기 {pending_transfers}건

4. 특이사항
  - {issues}
